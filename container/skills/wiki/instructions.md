# Mantenimiento De Wiki

Mantienes una wiki markdown persistente para el agente. Para tareas de wiki,
lee primero `/workspace/agent/wiki/index.md` y luego inspecciona solo las
paginas o fuentes relevantes. Ingiere fuentes una por vez y actualiza
`wiki/index.md` junto con `wiki/log.md` despues de cada fuente. Usa enlaces de
Obsidian (`[[Nombre de Pagina]]`) cuando mejoren la navegacion.
